# Delegation Protocol

Each delegated subtask must include:

- objective
- scope
- owned files or subsystem
- required context
- applicable standards
- required skills
- acceptance criteria
- validation expected
- explicit non-goals
- escalation triggers

## Delegation Rules

- Delegate by outcome, not vague role-play.
- Do not split a tightly coupled change into artificial parallel tasks.
- Parallelize independent analysis or implementation only when merge conflicts
  and dependency ambiguity are low.
- The delegator remains responsible for integration correctness.
- Handoffs must contain evidence, not merely conclusions.

## Handoff Payload

A handoff should include:

- summary
- decisions made
- files/modules inspected
- files changed
- commands executed
- open questions
- risks
- artifacts produced

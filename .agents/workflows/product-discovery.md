# Product Discovery Workflow

## Route
Product Manager → UX Researcher/Product Analyst → Competitive Analyst → Product Critic → Startup Strategist

## Steps
1. Define decision, not merely idea.
2. Define target user/job/problem.
3. Gather existing evidence.
4. Identify alternatives/status quo.
5. Estimate value, urgency, reachability, and strategic fit.
6. Product Critic argues against building.
7. Choose: build / prototype / experiment / research / defer / reject.
8. Convert chosen path into measurable acceptance or experiment criteria.

# Startup Experiment Workflow

## Route
Growth Lead or Product Manager → Analytics Specialist → Implementer(s) when needed → Product Analyst → Critic

## Steps
1. State falsifiable hypothesis.
2. Define target population.
3. Define intervention.
4. Define primary metric and guardrails.
5. Define decision rule before results.
6. Verify instrumentation.
7. Run only approved external actions.
8. Analyze result and uncertainty.
9. Decide ship / iterate / stop.
10. Record learning in `.agents/memory/lessons/` when durable.

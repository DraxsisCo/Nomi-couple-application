# Sales Process

## Purpose

Design a repeatable sales motion.

## Procedure

1. Define stages.
2. Define entry/exit criteria.
3. Define discovery questions.
4. Define evidence and CRM fields.
5. Define follow-up and handoff.

## Guardrails

- Do not create stages no one uses.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Onboarding Review

## Purpose

Review onboarding for time-to-value.

## Procedure

1. Define first value moment.
2. Map required setup.
3. Remove avoidable steps.
4. Improve guidance/error recovery.
5. Define activation metrics.

## Guardrails

- Do not confuse account creation with activation.

## Output

Return:
- result
- evidence
- risks
- required follow-up

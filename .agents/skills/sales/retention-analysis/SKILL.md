# Retention Analysis

## Purpose

Analyze retention drivers and churn risk.

## Procedure

1. Define retained behavior.
2. Segment cohorts.
3. Identify leading behaviors.
4. Review qualitative churn evidence.
5. Prioritize intervention hypotheses.

## Guardrails

- Retention definitions must match product value cadence.

## Output

Return:
- result
- evidence
- risks
- required follow-up

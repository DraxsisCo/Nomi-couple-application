# Technical Writing

## Purpose

Write durable technical documentation.

## Procedure

1. Identify audience/task.
2. Describe current truth.
3. Include prerequisites and failure modes.
4. Link authoritative sources.
5. Keep examples safe and maintainable.

## Guardrails

- Do not document secrets or unstable trivia.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Runbook Writing

## Purpose

Write an operational runbook.

## Procedure

1. Define trigger and scope.
2. List prerequisites/access.
3. Provide ordered safe steps.
4. Include verification and rollback.
5. Include escalation and evidence capture.

## Guardrails

- Do not hide irreversible steps inside routine commands.

## Output

Return:
- result
- evidence
- risks
- required follow-up

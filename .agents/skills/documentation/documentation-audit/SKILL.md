# Documentation Audit

## Purpose

Review docs for correctness, conflict, and staleness.

## Procedure

1. Compare docs with implementation/config.
2. Find contradictions.
3. Classify outdated vs missing.
4. Fix high-impact guidance.
5. Improve navigation.

## Guardrails

- Do not preserve stale docs out of sentimentality.

## Output

Return:
- result
- evidence
- risks
- required follow-up

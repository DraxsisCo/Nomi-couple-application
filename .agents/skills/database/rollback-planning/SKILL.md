# Rollback Planning

## Purpose

Define safe rollback or forward-fix strategy.

## Procedure

1. Identify irreversible states.
2. Define code/data compatibility window.
3. Prepare rollback sequence.
4. Define validation.
5. Identify human approval boundary.

## Guardrails

- A rollback plan that loses data is not a plan.

## Output

Return:
- result
- evidence
- risks
- required follow-up

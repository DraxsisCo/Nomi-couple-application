# Backup Restore Review

## Purpose

Review backup and restore readiness for risky DB work.

## Procedure

1. Confirm backup mechanism.
2. Check restore procedure evidence.
3. Define recovery point/time assumptions.
4. Verify access/ownership.
5. Record gaps.

## Guardrails

- Do not claim backups are usable without restore evidence.

## Output

Return:
- result
- evidence
- risks
- required follow-up

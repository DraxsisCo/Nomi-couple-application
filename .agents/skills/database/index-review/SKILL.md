# Index Review

## Purpose

Evaluate index need and design.

## Procedure

1. Identify query predicate/order.
2. Inspect existing indexes.
3. Estimate selectivity/write cost.
4. Choose key order.
5. Validate query plan if tooling exists.

## Guardrails

- Every index has write/storage cost.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Migration Planning

## Purpose

Plan schema/data migration sequencing and compatibility.

## Procedure

1. Classify additive vs destructive.
2. Assess locks/backfill size.
3. Plan expand/migrate/contract when needed.
4. Define rollout and rollback.
5. Define verification queries.

## Guardrails

- High-risk production execution requires human approval.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Data Flow Review

## Purpose

Trace sensitive data from input to storage/output.

## Procedure

1. Identify data classes.
2. Trace collection, processing, storage, transport, and logs.
3. Find unnecessary copies.
4. Check access controls and retention.
5. Document exposure points.

## Guardrails

- Minimize sensitive data propagation.

## Output

Return:
- result
- evidence
- risks
- required follow-up

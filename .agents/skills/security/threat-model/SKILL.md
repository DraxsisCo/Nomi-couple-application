# Threat Model

## Purpose

Model assets, actors, trust boundaries, and prioritized abuse cases.

## Procedure

1. Identify assets.
2. Map actors and entry points.
3. Draw trust/data boundaries.
4. List abuse cases.
5. Rank severity/likelihood.
6. Map controls and residual risk.

## Guardrails

- Focus on plausible attack paths, not theatrical apocalypse.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Abuse Case Analysis

## Purpose

Identify malicious or unintended misuse paths.

## Procedure

1. List valuable actions/resources.
2. Consider role/tenant abuse.
3. Consider automation/rate abuse.
4. Consider replay/duplication.
5. Map controls.

## Guardrails

- Include insider/misconfiguration cases when relevant.

## Output

Return:
- result
- evidence
- risks
- required follow-up

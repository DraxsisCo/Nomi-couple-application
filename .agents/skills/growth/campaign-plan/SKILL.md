# Campaign Plan

## Purpose

Plan a measurable marketing campaign.

## Procedure

1. Define audience.
2. Define message/offer.
3. Choose channels.
4. Define assets and tracking.
5. Define budget/guardrails if applicable.
6. Define review cadence.

## Guardrails

- Tie activity to measurable outcome.

## Output

Return:
- result
- evidence
- risks
- required follow-up

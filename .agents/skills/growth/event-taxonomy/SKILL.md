# Event Taxonomy

## Purpose

Design analytics event naming and properties.

## Procedure

1. Define business questions.
2. Define events around user actions/outcomes.
3. Standardize naming.
4. Control properties/cardinality.
5. Document ownership and versioning.

## Guardrails

- Do not track everything merely because you can.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Growth Experiment

## Purpose

Design a measurable growth experiment.

## Procedure

1. Define funnel stage.
2. State hypothesis.
3. Define audience/intervention.
4. Define primary metric and guardrails.
5. Set decision rule.
6. Plan instrumentation.

## Guardrails

- Do not run experiments without a decision rule.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Experiment Analysis

## Purpose

Analyze experiment results.

## Procedure

1. Check assignment/data quality.
2. Compare primary and guardrail metrics.
3. Assess uncertainty.
4. Check segment anomalies carefully.
5. Recommend ship/iterate/stop.

## Guardrails

- Do not cherry-pick secondary metrics.

## Output

Return:
- result
- evidence
- risks
- required follow-up

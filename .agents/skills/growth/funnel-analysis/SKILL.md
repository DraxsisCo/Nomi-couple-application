# Funnel Analysis

## Purpose

Analyze conversion between defined product/growth stages.

## Procedure

1. Define stages precisely.
2. Check event quality.
3. Segment where meaningful.
4. Find largest credible drop-offs.
5. Generate testable explanations.

## Guardrails

- Correlation is not causation.

## Output

Return:
- result
- evidence
- risks
- required follow-up

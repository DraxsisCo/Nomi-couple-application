# Keyword Analysis

## Purpose

Analyze keyword/search-intent opportunities.

## Procedure

1. Cluster by intent.
2. Map to funnel/user job.
3. Assess competition/evidence.
4. Prioritize themes.
5. Map to content/product pages.

## Guardrails

- Keywords are proxies for intent, not strategy by themselves.

## Output

Return:
- result
- evidence
- risks
- required follow-up

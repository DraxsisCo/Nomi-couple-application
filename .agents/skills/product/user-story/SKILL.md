# User Story

## Purpose

Write an implementable user story with useful context.

## Procedure

1. Identify user/role.
2. State outcome.
3. Add acceptance criteria.
4. Add constraints and permissions.
5. Add non-goals.

## Guardrails

- Avoid story templates that hide the actual problem.

## Output

Return:
- result
- evidence
- risks
- required follow-up

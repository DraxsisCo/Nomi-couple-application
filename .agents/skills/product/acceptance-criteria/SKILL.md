# Acceptance Criteria

## Purpose

Write testable acceptance criteria.

## Procedure

1. Use observable behavior.
2. Cover success/failure/permission edge cases.
3. Avoid vague adjectives.
4. Ensure each criterion can be evidenced.

## Guardrails

- 'Works correctly' is not acceptance criteria.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Edge Case Analysis

## Purpose

Systematically identify edge cases.

## Procedure

1. Map lifecycle states.
2. Consider empty/duplicate/stale/concurrent/unauthorized inputs.
3. Consider network/provider failure.
4. Prioritize realistic cases.

## Guardrails

- Do not enumerate nonsense for completeness theater.

## Output

Return:
- result
- evidence
- risks
- required follow-up

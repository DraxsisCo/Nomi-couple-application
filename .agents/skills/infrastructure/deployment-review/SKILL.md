# Deployment Review

## Purpose

Review deployment configuration and rollout safety.

## Procedure

1. Identify deployment order.
2. Check health/readiness.
3. Check config/schema compatibility.
4. Define rollout/rollback.
5. Verify observability and failure detection.

## Guardrails

- Do not execute production rollout without required approval.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Metrics Design

## Purpose

Design actionable operational/product metrics.

## Procedure

1. Define decision the metric supports.
2. Choose dimensions carefully.
3. Control cardinality.
4. Define units and aggregation.
5. Plan dashboards/alerts if operational.

## Guardrails

- Do not create high-cardinality labels casually.

## Output

Return:
- result
- evidence
- risks
- required follow-up

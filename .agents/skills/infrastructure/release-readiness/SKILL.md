# Release Readiness

## Purpose

Assess whether a release is ready.

## Procedure

1. Review changes and risk.
2. Confirm tests/build/security gates.
3. Check migrations/config.
4. Check rollout/rollback.
5. List blockers and approval needs.

## Guardrails

- Green CI alone is not release readiness.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Trace Design

## Purpose

Design distributed tracing for relevant critical paths.

## Procedure

1. Identify transaction boundaries.
2. Propagate context.
3. Create useful spans.
4. Avoid sensitive attributes.
5. Link failures to logs/metrics.

## Guardrails

- Tracing should answer a diagnostic question.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Github Actions

## Purpose

Create or review GitHub Actions workflows.

## Procedure

1. Inspect existing workflow policy.
2. Use least permissions.
3. Avoid secret exposure.
4. Pin actions when policy requires.
5. Keep jobs deterministic.
6. Preserve failure visibility.
7. Validate YAML/workflow logic.

## Guardrails

- Do not add broad write permissions by convenience.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Environment Config

## Purpose

Review environment configuration and secret injection.

## Procedure

1. Inventory required config.
2. Separate secret/non-secret values.
3. Validate startup requirements.
4. Avoid insecure production defaults.
5. Update examples/docs.

## Guardrails

- Real `.env` files do not belong in version control.

## Output

Return:
- result
- evidence
- risks
- required follow-up

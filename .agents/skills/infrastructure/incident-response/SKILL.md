# Incident Response

## Purpose

Coordinate a production incident response.

## Procedure

1. Stabilize impact.
2. Preserve evidence.
3. Identify scope.
4. Mitigate safely.
5. Communicate facts.
6. Verify recovery.
7. Create follow-up actions.

## Guardrails

- Do not make speculative destructive changes during diagnosis.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Realtime Design

## Purpose

Design realtime event behavior.

## Procedure

1. Define event source/consumer.
2. Define payload/version.
3. Handle reconnect/replay.
4. Define ordering/idempotency.
5. Plan authorization and presence.
6. Plan observability.

## Guardrails

- Connections are transient; state must have an authoritative source.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Semantic Review

## Purpose

Review HTML/ARIA semantics.

## Procedure

1. Prefer native elements.
2. Check accessible names.
3. Review roles/states/properties.
4. Check heading/landmark structure.
5. Remove redundant ARIA.

## Guardrails

- Bad ARIA is often worse than native HTML.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Accessibility Review

## Purpose

Review a feature for practical accessibility.

## Procedure

1. Check semantic structure.
2. Check labels/names.
3. Check keyboard path and focus.
4. Check dynamic announcements.
5. Check contrast if visual evidence exists.
6. Check reduced-motion considerations where relevant.

## Guardrails

- Do not certify compliance without adequate evidence.

## Output

Return:
- result
- evidence
- risks
- required follow-up

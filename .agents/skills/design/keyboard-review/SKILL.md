# Keyboard Review

## Purpose

Verify keyboard-only usability.

## Procedure

1. Traverse interactive controls.
2. Check focus order.
3. Check visible focus.
4. Check dialogs/menus trapping/restoration.
5. Check shortcuts for conflicts.

## Guardrails

- Mouse-only controls are defects.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Ui Spec

## Purpose

Produce an implementation-ready UI specification.

## Procedure

1. Define structure.
2. Define states.
3. Define interactions.
4. Define responsive behavior.
5. Reference existing primitives/tokens.
6. Define accessibility notes.

## Guardrails

- Avoid pixel-perfect inventions disconnected from the design system.

## Output

Return:
- result
- evidence
- risks
- required follow-up

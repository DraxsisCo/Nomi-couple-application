# User Flow

## Purpose

Design a user flow from trigger to completion and recovery.

## Procedure

1. Define entry conditions.
2. Map primary path.
3. Map errors/cancellation/empty states.
4. Identify permissions.
5. Minimize unnecessary steps.

## Guardrails

- Include recovery, not only happy path.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Design Critique

## Purpose

Critique a design against hierarchy, clarity, consistency, and task success.

## Procedure

1. Identify user goal.
2. Review visual hierarchy.
3. Review state clarity.
4. Review consistency.
5. Prioritize blocking usability issues.

## Guardrails

- Do not confuse personal taste with usability evidence.

## Output

Return:
- result
- evidence
- risks
- required follow-up

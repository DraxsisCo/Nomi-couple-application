# Interaction Review

## Purpose

Review an interaction for feedback, reversibility, and state clarity.

## Procedure

1. Check affordance.
2. Check immediate feedback.
3. Check loading/disabled states.
4. Check undo/confirmation based on risk.
5. Check error recovery.

## Guardrails

- Confirmation dialogs should correspond to meaningful risk.

## Output

Return:
- result
- evidence
- risks
- required follow-up

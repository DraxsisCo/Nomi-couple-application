# Responsive Review

## Purpose

Review behavior across viewport sizes.

## Procedure

1. Identify breakpoints from repository conventions.
2. Check navigation and dense layouts.
3. Check touch targets and overflow.
4. Check dialogs/forms/tables.
5. Record failures.

## Guardrails

- Hiding critical functionality is not a responsive strategy.

## Output

Return:
- result
- evidence
- risks
- required follow-up

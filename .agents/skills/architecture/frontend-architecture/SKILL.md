# Frontend Architecture

## Purpose

Review or design frontend module/component architecture.

## Procedure

1. Map route/screen boundaries.
2. Identify shared primitives.
3. Separate server state from UI state.
4. Define ownership.
5. Check code-splitting and dependency direction if relevant.

## Guardrails

- Avoid circular shared-component dependencies.

## Output

Return:
- result
- evidence
- risks
- required follow-up

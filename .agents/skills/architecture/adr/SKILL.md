# Adr

## Purpose

Create an Architecture Decision Record for a durable technical decision.

## Procedure

1. State context and forces.
2. List realistic options.
3. Record decision and rationale.
4. Describe consequences.
5. Link evidence and follow-up.

## Guardrails

- Do not use ADRs for trivial implementation details.

## Output

Return:
- result
- evidence
- risks
- required follow-up

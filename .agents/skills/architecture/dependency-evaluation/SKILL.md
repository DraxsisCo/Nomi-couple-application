# Dependency Evaluation

## Purpose

Evaluate whether a new dependency is justified.

## Procedure

1. Check existing capabilities.
2. Assess maintenance/security/licensing.
3. Compare runtime/platform alternatives.
4. Estimate integration and removal cost.
5. Document rationale.

## Guardrails

- Do not add a dependency for trivial convenience.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Failure Mode Analysis

## Purpose

Identify how a design fails and what users/operators experience.

## Procedure

1. List dependencies.
2. Enumerate partial failures.
3. Assess retry/timeout behavior.
4. Identify data consistency risks.
5. Define fallback and observability.

## Guardrails

- Do not treat 'catch exception' as a failure strategy.

## Output

Return:
- result
- evidence
- risks
- required follow-up

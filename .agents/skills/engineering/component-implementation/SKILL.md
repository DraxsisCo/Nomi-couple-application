# Component Implementation

## Purpose

Implement a frontend component or screen using repository patterns.

## Procedure

1. Search for existing primitives.
2. Define loading/error/empty/disabled states.
3. Implement semantics and keyboard behavior.
4. Integrate through the existing client data layer.
5. Add/update tests.

## Guardrails

- Do not duplicate backend authorization as a security control.

## Output

Return:
- result
- evidence
- risks
- required follow-up

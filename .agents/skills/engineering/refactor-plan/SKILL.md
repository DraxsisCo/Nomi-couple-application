# Refactor Plan

## Purpose

Plan a behavior-preserving refactor.

## Procedure

1. Define observable behavior to preserve.
2. Add characterization tests where coverage is weak.
3. Split structural steps from behavior changes.
4. Keep each step reviewable.
5. Validate after each meaningful boundary change.

## Guardrails

- Do not combine broad refactors with unrelated features.

## Output

Return:
- result
- evidence
- risks
- required follow-up

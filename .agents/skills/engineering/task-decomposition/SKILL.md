# Task Decomposition

## Purpose

Break a request into coherent, dependency-aware implementation slices.

## Procedure

1. Identify deliverables.
2. Map dependencies.
3. Separate parallelizable from sequential work.
4. Assign ownership.
5. Attach validation to each slice.

## Guardrails

- Avoid creating tasks that exist only to simulate more agents.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Acceptance Testing

## Purpose

Verify explicit acceptance criteria against implemented behavior.

## Procedure

1. List criteria.
2. Map each criterion to evidence.
3. Execute or inspect verification.
4. Record pass/fail.
5. Flag ambiguous criteria.

## Guardrails

- No criterion is 'implicitly passed'.

## Output

Return:
- result
- evidence
- risks
- required follow-up

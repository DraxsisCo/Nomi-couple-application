# Unit Testing

## Purpose

Write focused tests for isolated business or utility behavior.

## Procedure

1. Identify behavior boundaries.
2. Test success and meaningful failure cases.
3. Keep fixtures minimal.
4. Avoid over-mocking implementation details.
5. Run focused tests.

## Guardrails

- Tests should describe behavior, not internal call choreography.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# E2E Testing

## Purpose

Test critical user journeys end-to-end.

## Procedure

1. Choose high-value journey.
2. Prepare deterministic state.
3. Exercise real UI/API path.
4. Assert user-visible outcome.
5. Capture failure diagnostics.

## Guardrails

- Do not make the full suite depend on fragile timing.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Frontend Testing

## Purpose

Select and implement frontend behavioral tests.

## Procedure

1. Test user-observable behavior.
2. Cover async/loading/error states.
3. Use accessible selectors.
4. Avoid asserting incidental DOM structure.
5. Run focused tests.

## Guardrails

- Do not test CSS implementation trivia unless it is the requirement.

## Output

Return:
- result
- evidence
- risks
- required follow-up

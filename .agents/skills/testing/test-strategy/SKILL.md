# Test Strategy

## Purpose

Create a risk-based validation plan.

## Procedure

1. Map risks to test layers.
2. Identify critical paths.
3. Prioritize fast deterministic coverage.
4. Define manual/exploratory checks only where automation is unsuitable.
5. Specify release blockers.

## Guardrails

- Not every behavior belongs in E2E.

## Output

Return:
- result
- evidence
- risks
- required follow-up

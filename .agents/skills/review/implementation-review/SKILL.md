# Implementation Review

## Purpose

Review implementation against requirements and architecture.

## Procedure

1. Read acceptance criteria.
2. Inspect diff in context.
3. Check correctness/error paths.
4. Check tests.
5. Check scope and maintainability.
6. Record blocking/non-blocking findings.

## Guardrails

- Review evidence, not author confidence.

## Output

Return:
- result
- evidence
- risks
- required follow-up

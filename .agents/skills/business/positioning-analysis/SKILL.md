# Positioning Analysis

## Purpose

Clarify category, target customer, problem, alternatives, and differentiated value.

## Procedure

1. Define ICP/context.
2. Name alternatives.
3. Identify unique strengths.
4. Draft positioning logic.
5. Test for clarity and credibility.

## Guardrails

- Avoid vague 'all-in-one, AI-powered, revolutionary' sludge.

## Output

Return:
- result
- evidence
- risks
- required follow-up

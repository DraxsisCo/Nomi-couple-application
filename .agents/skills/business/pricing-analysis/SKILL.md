# Pricing Analysis

## Purpose

Analyze pricing using value, willingness-to-pay evidence, costs, and alternatives.

## Procedure

1. Define customer segments.
2. Map value metric.
3. Compare alternatives.
4. Model price points.
5. Identify evidence gaps and tests.

## Guardrails

- Cost-plus pricing is not automatically value-based pricing.

## Output

Return:
- result
- evidence
- risks
- required follow-up

# Oauth Review

## Purpose

Review OAuth/OIDC integration behavior.

## Procedure

1. Check redirect URI handling.
2. Validate state/nonce as applicable.
3. Protect tokens.
4. Review scopes.
5. Handle refresh/revocation.
6. Check account-linking edge cases.

## Guardrails

- Use least privilege scopes.

## Output

Return:
- result
- evidence
- risks
- required follow-up
